# Course 1: What is Data Science? (Foundations, Ecosystem, Roles & Big Data)

## 1.1 The Definition & Pillars of Data Science
Data Science is an empirical, scientific, and computational discipline dedicated to discovering hidden structures, predictive signals, and actionable intelligence from complex, noisy datasets. It bridges mathematical rigor with scalable software engineering to solve concrete operational and business problems.

### The 3 Core Pillars:
1. **Computer Science & Software Engineering**: Algorithms, data structures, runtime complexity ($O(n)$ notation), memory management, database design, API construction, distributed computing.
2. **Mathematics & Statistics**: Probability theory, linear algebra, multivariable calculus, hypothesis testing, Bayesian inference, statistical learning theory.
3. **Domain Expertise & Business Strategy**: Understanding market drivers, customer behaviors, clinical requirements, regulatory frameworks, translating analytical findings into strategic decision-making.

## 1.4 Big Data & The 5 V's Framework
Modern enterprise datasets are characterized by the **5 V's**:
* **Volume**: Massive storage requirements scaling from Terabytes ($10^{12}$) to Petabytes ($10^{15}$) and Exabytes ($10^{18}$).
* **Velocity**: Rapid ingestion speed (e.g., millions of IoT sensor pings per second, real-time financial market order books).
* **Variety**: Structural heterogeneity:
  * *Structured*: Tabular SQL rows, strict relational schemas.
  * *Semi-Structured*: JSON payloads, XML, NoSQL documents.
  * *Unstructured*: Raw text, audio streams, high-resolution satellite imagery, video feeds.
* **Veracity**: Degree of trustworthiness, noise level, measurement error, missingness, and provenance of data.
* **Value**: The tangible economic return, operational optimization, or scientific advancement unlocked through analytics.

# Course 3: Data Science Methodology (John Rollins' 10-Stage Iterative Scientific Lifecycle)

## 3.1 Overview & Comparison with Industry Frameworks
The **John Rollins Data Science Methodology** provides a cyclical, iterative 10-stage scientific framework designed specifically to ensure data science projects deliver actionable business value rather than remaining academic exercises.

### Framework Comparison:
* **John Rollins Methodology**: 10 explicit, highly iterative stages with direct feedback loops between preparation, modeling, and evaluation.
* **CRISP-DM (Cross-Industry Standard Process for Data Mining)**: 6 broader phases (Business Understanding, Data Understanding, Data Preparation, Modeling, Evaluation, Deployment).
* **OSEMN**: 5 streamlined steps (Obtain, Scrub, Explore, Model, iNterpret).

### Detailed Breakdown of Every Stage:

#### Stage 1: Business Understanding
* Define clear, unambiguous problem statements with quantifiable KPIs.
* Avoid vague mandates like *"We need AI"*; define precise objectives: *"Predict loan default probability within 30 seconds of application to reduce default loss by 12% without decreasing approval volume."*

#### Stage 2: Analytic Approach
* Select the analytical paradigm:
  * **Descriptive**: Summary statistics, clustering customer segments.
  * **Diagnostic**: Root-cause failure analysis, correlation matrices.
  * **Predictive**: Supervised regression (predicting sales volume) or classification (predicting customer churn).
  * **Prescriptive**: Operations research, route optimization, reinforcement learning.

#### Stage 3: Data Requirements
* Specify data schema, feature definitions, formats (numeric, categorical, datetime, text), sampling frequencies, and historical lookback windows.

#### Stage 4: Data Collection
* Ingest data across disparate silos: transactional relational databases (SQL), document stores (NoSQL), REST APIs, cloud object storage, streaming telemetry, web scraping.

#### Stage 5: Data Understanding (EDA)
* Descriptive statistics (Mean, Median, Standard Deviation, Skewness, Kurtosis).
* Assess data quality: missingness percentages, duplicate records, class imbalance ratios, anomalous outliers.

#### Stage 6: Data Preparation (Wrangling)
* The most time-consuming phase (~70?80% of project time).
* Missing value imputation (MCAR/MAR/MNAR).
* Outlier clipping or removal (Z-score/IQR).
* Feature transformation (Log, Box-Cox, Power transforms).
* Categorical encoding (One-Hot, Ordinal, Target Encoding).
* Feature scaling (Min-Max, Standardization).
* **Strict Anti-Data Leakage Rules**: Feature transformations must be fitted solely on training splits.

#### Stage 7: Modeling
* Select algorithmic families (Tree-based ensembles, Generalized Linear Models, Support Vector Machines, Neural Networks).
* Partition data into **Training** (e.g., 70%), **Validation** (e.g., 15%), and **Test** (e.g., 15%) sets.
* Train baseline models and perform hyperparameter optimization via Cross-Validation.

#### Stage 8: Evaluation
* Evaluate performance on held-out test data using appropriate metrics:
  * Classification: Precision, Recall, F1-Score, ROC-AUC, PR-AUC, Confusion Matrix.
  * Regression: RMSE, MAE, $R^2$, Adjusted $R^2$, Mean Absolute Percentage Error (MAPE).
* Perform diagnostic error analysis to inspect false positives and false negatives.

#### Stage 9: Deployment
* Package the trained model into a production artifact (`joblib`, `ONNX`, `pickle`).
* Deploy as a containerized microservice (Docker + FastAPI) or batch inference cron job.

#### Stage 10: Feedback & Maintenance
* Continuous monitoring in production:
  * **Data Drift (Covariate Shift)**: Input feature distribution shifts over time: $P(X)_{	ext{train}} 
eq P(X)_{	ext{prod}}$.
  * **Concept Drift**: The relationship between inputs and target changes: $P(Y \mid X)_{	ext{train}} 
eq P(Y \mid X)_{	ext{prod}}$.
* Automated alerting triggers retraining pipelines when accuracy falls below predefined thresholds.

## 4.3 Object-Oriented Programming (OOP) in Machine Learning Pipelines

```python
from abc import ABC, abstractmethod
import numpy as np

class BaseEstimator(ABC):
    """Abstract base class enforcing standard fit/predict interface."""
    @abstractmethod
    def fit(self, X: np.ndarray, y: np.ndarray):
        pass
        
    @abstractmethod
    def predict(self, X: np.ndarray) -> np.ndarray:
        pass

class CustomStandardScaler:
    """Custom Z-score scaler following Scikit-Learn transformer conventions."""
    def __init__(self):
        self.mean_ = None
        self.scale_ = None
        
    def fit(self, X: np.ndarray):
        X = np.asarray(X, dtype=np.float64)
        self.mean_ = np.mean(X, axis=0)
        self.scale_ = np.std(X, axis=0)
        # Prevent division by zero for constant features
        self.scale_[self.scale_ == 0.0] = 1.0
        return self
        
    def transform(self, X: np.ndarray) -> np.ndarray:
        if self.mean_ is None or self.scale_ is None:
            raise RuntimeError("Scaler must be fitted before transforming data!")
        X = np.asarray(X, dtype=np.float64)
        return (X - self.mean_) / self.scale_
        
    def fit_transform(self, X: np.ndarray) -> np.ndarray:
        return self.fit(X).transform(X)
```

# Course 6: Databases and SQL for Data Science with Python (RDBMS, Advanced SQL & ACID)

## 6.1 Relational Database Theory, Normalization & Keys
* **Relational Model (Codd's Relational Algebra)**: Represents data as mathematical relations (tables) composed of ordered tuples (rows) and named attributes (columns).
* **Key Taxonomy**:
  * **Candidate Key**: Minimal set of attributes uniquely identifying a record.
  * **Primary Key (PK)**: Selected candidate key chosen as the unique identifier. Cannot contain `NULL`.
  * **Surrogate Key**: Artificially generated numeric ID (e.g., `AUTO_INCREMENT` / `SERIAL`) without business meaning.
  * **Foreign Key (FK)**: Attribute in a child table enforcing referential integrity to a parent table's Primary Key.
* **Database Normalization**:
  * **1NF (First Normal Form)**: Atomic column values; no repeating groups or arrays.
  * **2NF (Second Normal Form)**: Meets 1NF + All non-key attributes fully functionally dependent on the entire Primary Key (no partial dependencies).
  * **3NF (Third Normal Form)**: Meets 2NF + No transitive dependencies (non-key attributes must depend *only* on the Primary Key).

### Imputation Methods Comparison:
1. **Mean / Median Imputation**:
   * *Mean*: $\hat{x} = \frac{1}{N} \sum x_i$ (For normal, symmetric continuous data).
   * *Median*: $\hat{x} = \text{Median}(X)$ (For skewed continuous data with extreme outliers).
2. **K-Nearest Neighbors (KNN) Imputation**:
   * Imputes missing feature value as the distance-weighted average of the $K$ closest instances in feature space:
   $$\hat{x}_{i, j} = \frac{\sum_{k \in \mathcal{N}_K(i)} w_k \cdot x_{k, j}}{\sum_{k \in \mathcal{N}_K(i)} w_k}, \quad w_k = \frac{1}{d(x_i, x_k)}$$
3. **MICE (Multivariate Imputation by Chained Equations)**:
   * Iteratively models each missing feature as a function of all other features via chained regression models until convergence.

## 7.2 Outlier Detection Mathematics
* **Z-Score Method (Parametric)**:
  $$Z = \frac{x - \mu}{\sigma}$$
  * Flagged as outlier if $|Z| > 3.0$ (representing $< 0.27\%$ of a normal distribution).
* **Interquartile Range (IQR) Method (Non-parametric / Tukey's Fences)**:
  $$\text{IQR} = Q_3 - Q_1$$
  $$\text{Lower Fence} = Q_1 - 1.5 \times \text{IQR}, \quad \text{Upper Fence} = Q_3 + 1.5 \times \text{IQR}$$
  * Extreme Outliers: Points beyond $Q_1 - 3.0 \times \text{IQR}$ or $Q_3 + 3.0 \times \text{IQR}$.

---

## 7.3 Data Transformations, Scaling & Normalization
* **Logarithmic Transformation**: Compresses wide dynamic ranges and corrects positive right-skewness:
  $$y = \ln(x + 1)$$
* **Box-Cox Power Transformation**:
  $$y^{(\lambda)} = \begin{cases} \frac{x^\lambda - 1}{\lambda} & \text{if } \lambda \neq 0 \\ \ln(x) & \text{if } \lambda = 0 \end{cases} \quad (x > 0)$$
* **Min-Max Feature Scaling**:
  $$x_{\text{scaled}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}} \in [0, 1]$$
* **Standardization (Z-score Normalization)**:
  $$x_{\text{std}} = \frac{x - \mu}{\sigma} \sim \mathcal{N}(0, 1)$$
* **Robust Scaler (Resistant to Outliers)**:
  $$x_{\text{robust}} = \frac{x - Q_2(X)}{\text{IQR}(X)}$$

## 7.4 Categorical Encoding & The Dummy Variable Trap
* **One-Hot Encoding**: Converts categorical features with $K$ unique levels into $K$ binary indicator columns.
* **The Dummy Variable Trap (Perfect Multicollinearity)**:
  * If all $K$ dummy variables are included alongside an intercept term $\beta_0$, the dummy columns sum to 1, creating a linearly dependent singular matrix:
  $$\sum_{j=1}^K D_j = 1 = x_0$$
  * *Remedy*: Drop one category (`drop_first=True`), producing $K-1$ dummy indicators.

## 7.5 Statistical Inference: Pearson Correlation ($r$) & ANOVA ($F$-test)

### A. Pearson Linear Correlation Coefficient ($r$)
$$r = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^n (x_i - \bar{x})^2 \sum_{i=1}^n (y_i - \bar{y})^2}}, \quad -1 \le r \le +1$$
* **Hypothesis Testing**:
  * Null Hypothesis $H_0: \rho = 0$ (No linear association).
  * Alternative Hypothesis $H_1: \rho \neq 0$.
  * Test statistic: $t = r \sqrt{\frac{n - 2}{1 - r^2}} \sim t_{n-2}$.
  * $p < 0.05$: Reject $H_0$; correlation is statistically significant.

### B. One-Way Analysis of Variance (ANOVA)
Tests if the means of $K$ distinct categorical groups are equal:
$$F = \frac{\text{Between-Group Mean Square (MSB)}}{\text{Within-Group Mean Square (MSW)}} = \frac{\text{SSB} / (K - 1)}{\text{SSW} / (N - K)}$$
* A large $F$-statistic accompanied by $p < 0.05$ indicates that at least one group mean significantly differs from the others.

## 7.6 Regression Modeling: OLS, Multiple Regression & Assumptions

### A. Ordinary Least Squares (OLS) Normal Equation Derivation
Model:
$$y = X \beta + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2 I)$$
Cost Function (Residual Sum of Squares):
$$J(\beta) = \|y - X \beta\|^2 = (y - X \beta)^T (y - X \beta) = y^T y - 2 \beta^T X^T y + \beta^T X^T X \beta$$
Setting the gradient with respect to $\beta$ to zero:
$$\nabla_\beta J(\beta) = -2 X^T y + 2 X^T X \beta = 0 \implies X^T X \beta = X^T y$$
$$\mathbf{\beta^* = (X^T X)^{-1} X^T y}$$

### B. The 5 Classical Gauss-Markov Assumptions for OLS
1. **Linearity**: The relationship between features $X$ and target $y$ is linear in parameters.
2. **Strict Exogeneity**: Errors have conditional mean zero: $\mathbb{E}[\epsilon \mid X] = 0$.
3. **No Multicollinearity**: The design matrix $X$ has full column rank; features are not perfectly linearly correlated ($	ext{VIF} < 5.0$).
4. **Homoscedasticity**: Error variance is constant across all observations: $\text{Var}(\epsilon_i \mid X) = \sigma^2$.
5. **No Autocorrelation**: Errors are uncorrelated across observations: $\text{Cov}(\epsilon_i, \epsilon_j) = 0 \; (i \neq j)$.


* **High Bias (Underfitting)**: Model is too simplistic to capture true patterns (e.g., fitting a linear model to a non-linear parabolic curve).
* **High Variance (Overfitting)**: Model fits random noise and fluctuations in the training set (e.g., high-degree unregularized polynomial, unpruned decision tree).
* **Remedies**:
  * *To reduce Bias*: Increase model complexity, add polynomial/interaction features, switch to non-linear algorithms.
  * *To reduce Variance*: Apply regularization ($L_1/L_2$), prune decision trees, gather more data, perform feature selection, use ensemble averaging (Bagging/Random Forests).

## 10.2 Supervised Classification Algorithms

### A. K-Nearest Neighbors (KNN)
* Non-parametric, lazy learner storing training vectors in memory.
* Prediction for new instance $x$: Majority vote among $K$ nearest instances:
  $$\hat{y} = \text{mode}\left(\{y_i : x_i \in \mathcal{N}_K(x)\}\right)$$
* Requires strict feature scaling (e.g., `StandardScaler`) to prevent high-magnitude features from dominating distance calculations.

### B. Decision Trees (CART Algorithm)
* Iteratively partitions feature space into axis-aligned rectangular regions.
* **Entropy**:
  $$H(S) = - \sum_{c=1}^C p_c \log_2(p_c)$$
* **Gini Impurity**:
  $$G(S) = 1 - \sum_{c=1}^C p_c^2$$
* **Pruning via Minimal Cost-Complexity**:
  $$R_\alpha(T) = R(T) + \alpha |T|$$

### C. Random Forest Ensembles (Bagging)
* Combines $B$ bootstrapped decision trees:
  1. Draw $B$ bootstrap datasets of size $N$ with replacement from the training set.
  2. At each tree node split, randomly sample $m = \sqrt{p}$ features.
  3. Grow trees to maximum depth without pruning.
  4. Aggregate predictions: $\hat{y} = \text{mode}(\hat{y}_1, \dots, \hat{y}_B)$.
* **Out-of-Bag (OOB) Error**: Evaluates trees on instances omitted during bootstrap sampling (~36.8% of data), providing an unbiased validation metric without explicit cross-validation.

### D. Logistic Regression & Binary Cross-Entropy
* Models log-odds (logit):
  $$\ln\left( \frac{p(x)}{1 - p(x)} \right) = w^T x + b \implies p(x) = \sigma(w^T x + b) = \frac{1}{1 + e^{-(w^T x + b)}}$$
* **Log-Loss Optimization via Gradient Descent**:
  $$J(w) = - \frac{1}{N} \sum_{i=1}^N \left[ y_i \ln \hat{y}_i + (1 - y_i) \ln(1 - \hat{y}_i) \right]$$
  $$\frac{\partial J}{\partial w} = \frac{1}{N} X^T (\hat{y} - y)$$

### E. Support Vector Machines (SVM) & Kernel Formulation
* Finds optimal hyperplane with maximum separation margin $\frac{2}{\|w\|}$:
  $$\min_{w, b, \xi} \frac{1}{2} \|w\|^2 + C \sum_{i=1}^N \xi_i \quad \text{subject to } y_i (w^T \Phi(x_i) + b) \ge 1 - \xi_i, \quad \xi_i \ge 0$$
* **RBF Kernel**:
  $$K(x_i, x_j) = \exp(-\gamma \|x_i - x_j\|^2)$$
  * High $C$: Small margin, low tolerance for misclassifications (High Variance).
  * High $\gamma$: Narrow Gaussian bell curvature, complex decision boundary (High Variance).

### B. DBSCAN (Density-Based Spatial Clustering of Applications with Noise)
* Groups points with high local density; resilient to arbitrary cluster shapes and automatically isolates anomalies/noise points (labeled `-1`).
* **Parameters**:
  * `eps` ($\epsilon$): Radius of neighborhood.
  * `min_samples`: Minimum number of points within $\epsilon$ required to form a dense core region.

### C. Principal Component Analysis (PCA)
* Linear dimensionality reduction projecting data along directions of maximal variance:
  1. Center feature matrix $X$ ($\mu = 0$).
  2. Compute sample covariance matrix: $\Sigma = rac{1}{N-1} X^T X$.
  3. Perform Eigen-decomposition: $\Sigma v_i = \lambda_i v_i$.
  4. Sort eigenvectors $v_i$ by decreasing eigenvalues $\lambda_i$.
  5. Project data into top $K$ principal components: $Z = X V_K$.

## 13.4 U.S. EEOC Legal Boundaries in Hiring
Under U.S. Equal Employment Opportunity Commission (EEOC) laws, interviewers **cannot legally inquire** about:
* Age or date of birth.
* Marital status, pregnancy, plans for marriage, or children.
* Race, ethnicity, or color.
* Religion or religious practices.
* Gender identity, sexual orientation, or biological sex.
* Physical or mental disabilities (questions must strictly evaluate ability to perform essential job duties).

## ?? Top 10 Data Science Mental Models for Practitioners
1. **The Bias-Variance Trade-Off**: Total generalization error is bounded by model underfitting (Bias) vs overfitting (Variance). Tuning regularizers balances this frontier.
2. **The No Free Lunch Theorem**: No universally superior machine learning model exists. The optimal algorithm is always contingent on dataset geometry, sample size, and noise structure.
3. **Strict Data Leakage Prevention**: Never compute preprocessing statistics ($\mu, \sigma$, target encodings, imputations) on the test partition. Fit on train; transform on test.
4. **The Curse of Dimensionality**: High-dimensional feature spaces become exponentially sparse, degrading distance metrics (KNN/K-Means). Combat via PCA, feature selection, or $L_1$ Lasso regularization.
5. **Class Imbalance Realities**: Raw accuracy is a misleading metric for imbalanced classes ($< 5\%$ minority). Prioritize PR-AUC, F1-Score, and synthetic augmentation (CTGAN/SMOTE).
6. **Correlation Does Not Imply Causation**: Observational correlation ($r$) can stem from confounding variables, selection bias, or reverse causality. Randomized experiments (A/B tests) establish true causation.
7. **Occam's Razor (Parsimony)**: Given two models with comparable predictive power, always select the simpler, more interpretable model with fewer parameters.
8. **Simpson's Paradox**: Aggregate population trends can completely reverse when conditioned on underlying confounding subgroups.
9. **Explainability Over Black-Box Complexity**: In mission-critical and regulated enterprise environments (healthcare, lending, insurance), an interpretable model with explainable feature attribution (SHAP) is vastly superior to an opaque black box.
10. **Machine Learning as a Living Production System**: Deployment is not the finish line. Production models continuously degrade due to covariate data drift and concept drift, requiring automated monitoring, alerting, and retraining pipelines.
