## Key Modules & Core Tools Architecture

### Module 1: Languages, Libraries & Data Science Tools Overview
- **Data Science Languages**:
  - **Python**: Primary language for AI/ML, data analysis, web scraping, and automation.
  - **R**: Specialized for statistical computing, bioinformatics, advanced visualizations (ggplot2).
  - **SQL (Structured Query Language)**: Industry standard for querying relational databases (PostgreSQL, MySQL, SQLite, DB2).
  - **Other Languages**: Julia, Java, Scala, C++.

- **Key Python Data Science Libraries**:
  - **Data Manipulation**: Pandas (DataFrames), NumPy (N-dimensional arrays, vectorized vector operations).
  - **Data Visualization**: Matplotlib (2D plotting), Seaborn (statistical graphics), Plotly, Folium (interactive maps).
  - **Machine Learning & AI**: Scikit-learn (regression, classification, clustering), TensorFlow, PyTorch, Keras.

- **Key R Data Science Libraries**:
  - `ggplot2` (data visualization based on Grammar of Graphics), `dplyr` (data manipulation), `caret` (machine learning), `tidyr` (data cleaning).

### Module 2: Open Source Tools - JupyterLab, RStudio & Git/GitHub
- **Jupyter Notebooks & JupyterLab**:
  - **Kernel**: Computational engine that executes code written in notebook cells (Python 3, R, Julia).
  - **Cell Types**: 
    1. **Code Cells**: Executable Python/R statements.
    2. **Markdown Cells**: Text formatted with headers, lists, LaTeX formulas, links, and embedded images.
    3. **Raw Cells**: Plain unformatted text.
  - **Keyboard Shortcuts**: `Shift + Enter` (Run cell), `Esc + A` (Insert above), `Esc + B` (Insert below), `Esc + M` (Convert to Markdown).

- **RStudio IDE**:
  - Integrated Development Environment for R.
  - 4 Panes: Source Editor, Console, Environment/History, Files/Plots/Packages/Help.

- **Git & GitHub Version Control**:
  - **Git**: Distributed version control system tracking source code changes locally.
  - **GitHub**: Cloud-based hosting service for Git repositories.
  - **Core Git Commands**:
    ```bash
    git init                           # Initialize local repository
    git clone <url>                    # Clone remote repository
    git add .                          # Stage files
    git commit -m "commit message"     # Record changes locally
    git remote add origin <url>        # Connect to remote origin
    git push -u origin main            # Push local commits to main branch
    ```
