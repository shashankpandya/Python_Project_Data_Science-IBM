## Module 1: Defining Data Science & What Data Scientists Do

### The Core Definition
Data Science is the study of data through the scientific method — forming hypotheses, collecting evidence (data), and drawing conclusions — to extract actionable business intelligence.

**Key formula of a good data scientist**:
> Curiosity × Domain Knowledge × Programming Skills × Statistical Thinking = Impact

### The Full Data Science Workflow
| Step | Activity | Tools |
|:---|:---|:---|
| **1. Define Problem** | Business hypothesis, KPIs, success criteria | Whiteboard, Stakeholder interviews |
| **2. Data Collection** | APIs, databases, web scraping, IoT sensors, CSV | Python requests, SQL, Kafka |
| **3. Data Cleaning** | Handle NaN, outliers, type errors, duplicates | Pandas, OpenRefine |
| **4. EDA** | Distributions, correlations, feature importance | Matplotlib, Seaborn, Pandas Profiling |
| **5. Model Building** | Algorithm selection, training, tuning | Scikit-learn, XGBoost, TensorFlow |
| **6. Evaluation** | Accuracy, F1, R², ROC-AUC | Scikit-learn metrics |
| **7. Deployment** | REST API, dashboard, cloud service | Flask, Streamlit, IBM Watson, AWS |
| **8. Monitoring** | Model drift detection, retraining triggers | MLflow, Evidently, Prometheus |

### Data Science vs Adjacent Roles
| Role | Focus | Key Skills |
|:---|:---|:---|
| **Data Engineer** | Builds data pipelines and infrastructure | Spark, Hadoop, Kafka, SQL, Airflow |
| **Data Analyst** | Describes and visualizes historical data | SQL, Excel, Tableau, Power BI |
| **Data Scientist** | Predicts future events, builds models | Python/R, ML, statistics, storytelling |
| **ML Engineer** | Productionizes and scales ML systems | MLOps, Docker, Kubernetes, CI/CD |
| **AI Researcher** | Advances the theoretical foundations of AI | Deep Learning, Mathematics, PyTorch |

## Module 2: Big Data, Machine Learning & Real-World Applications

### The 5 Vs of Big Data
| V | Meaning | Example |
|:---|:---|:---|
| **Volume** | Scale of data generated | 2.5 quintillion bytes/day globally |
| **Velocity** | Speed of data generation | Real-time stock ticks, GPS streams |
| **Variety** | Diversity of data formats | SQL tables, JSON, images, audio, video |
| **Veracity** | Trustworthiness and accuracy | Survey bias, sensor noise, missing data |
| **Value** | Business utility derived | Revenue increase, cost savings |

### Machine Learning Categories
**Supervised Learning** (labeled training data):
- **Regression**: Predict continuous values → Linear Regression, Decision Tree Regressor
- **Classification**: Predict discrete categories → Logistic Regression, SVM, Random Forest

**Unsupervised Learning** (no labels):
- **Clustering**: Group similar observations → K-Means, DBSCAN, Hierarchical
- **Dimensionality Reduction**: Compress features → PCA, t-SNE, UMAP
- **Association Rules**: Find co-occurrence patterns → Apriori, FP-Growth

**Reinforcement Learning** (agent + environment + reward):
- Game playing (AlphaGo), robotics control, autonomous vehicles, recommendation systems

### High-Impact Industry Applications
| Industry | Data Science Use Case | Business Impact |
|:---|:---|:---|
| **Healthcare** | Cancer detection from CT scans, readmission prediction | Save lives, reduce cost |
| **Finance** | Real-time fraud detection, credit scoring | Prevent losses |
| **E-commerce** | Collaborative filtering recommendation engines | Increase revenue 35%+ |
| **Transportation** | Route optimization, demand forecasting (Uber/Lyft) | Reduce idle time |
| **Manufacturing** | Predictive maintenance (IoT sensor ML) | Minimize downtime |
| **Climate** | Wildfire prediction, flood mapping | Disaster preparedness |

### Key Big Data Processing Frameworks
| Technology | Purpose | When to Use |
|:---|:---|:---|
| **Apache Hadoop** | Distributed storage (HDFS) + MapReduce batch processing | TB–PB scale, batch jobs |
| **Apache Spark** | In-memory distributed processing (100x faster than MapReduce) | Real-time + batch, ML |
| **Apache Kafka** | Real-time streaming data ingestion | Live event streams, IoT |
| **Apache Airflow** | Orchestrates complex pipeline workflows (DAGs) | Scheduling ETL workflows |

## Module 3: Data Science Careers & Professional Skills

### Core Skill Sets Required
**Technical Skills**:
- **Programming**: Python (primary), R, SQL (essential), Scala, Julia
- **Math & Statistics**: Linear algebra, calculus, probability, hypothesis testing, Bayesian inference
- **Machine Learning**: Supervised, unsupervised, deep learning architectures
- **Data Engineering**: ETL, data warehouse design, cloud storage (S3, GCS, Azure Blob)
- **Visualization**: Matplotlib, Seaborn, Plotly, Tableau, Power BI

**Soft Skills**:
- Intellectual curiosity and critical thinking
- Domain expertise in the industry vertical
- Storytelling and communication to non-technical stakeholders
- Project management and iterative experimentation mindset

### Structure of a Professional Data Science Report
1. **Executive Summary** — Key findings in 3–5 bullets, ROI/business impact
2. **Problem Statement** — Business question, hypothesis, and scope
3. **Data Sources & Methodology** — Where data came from, how it was cleaned, model selected
4. **Results & Visualizations** — Charts, maps, and model performance metrics
5. **Recommendations** — Actionable steps backed by evidence
6. **Limitations & Future Work** — Biases, data gaps, next iteration ideas

### Structured vs. Semi-Structured vs. Unstructured Data
| Type | Definition | Examples |
|:---|:---|:---|
| **Structured** | Organized in rows/columns with schema | SQL databases, CSV, Excel |
| **Semi-Structured** | Self-describing, no fixed schema | JSON, XML, YAML, emails |
| **Unstructured** | No predefined form | Images, audio, video, PDFs, social media text |
