# Python Project for Data Science - IBM

## 📈 Analyzing Historical Stock and Revenue Data & Building a Dashboard

This repository contains the complete implementation for the IBM **Python Project for Data Science** course final assessment.

### 📌 Project Overview
As a Data Scientist / Analyst working for a financial analytics firm, this project extracts and visualizes historical stock prices and revenue data for **Tesla (TSLA)** and **GameStop (GME)** to compare share performance against financial revenue growth over time.

---

## 🛠️ Data Sources & Technologies Used
- **yfinance**: Extracted historical stock market data (Open, High, Low, Close, Volume).
- **BeautifulSoup & Requests**: Web-scraped quarterly revenue datasets from HTML tables.
- **Pandas**: Structured, cleansed, and converted dataset numerical values.
- **Plotly Graph Objects**: Built interactive two-panel stock price vs. revenue dashboards.

---

## 📁 Repository Structure
- `Analyzing_Historical_Stock_Data_Dashboard.ipynb`: Complete Jupyter Notebook containing all 6 exercises fully executed with output graphs displayed.
- `README.md`: Project documentation & overview.

---

## 🚀 Key Results & Insights
1. **Tesla (TSLA)**: Showed significant exponential growth in both stock price and quarterly revenue between 2018 and 2021.
2. **GameStop (GME)**: Experienced a major stock price surge during early 2021 driven by market dynamics, while revenue trends remained consistent.
